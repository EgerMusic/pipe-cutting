# Раскрой труб

Программа для раскроя конусных свай: сколько труб купить и как их резать.

**Рабочая ссылка:** https://egermusic.github.io/pipe-cutting/

Ноутбук дома не нужен. Открой ссылку в Chrome или Edge.

## Как пользоваться на работе

1. Открой ссылку выше (лучше сохранить в закладки).
2. Укажи диаметр, длину заготовки (обычно 12000 мм), пропил и минимальный остаток.
3. Если нужно — включи «конус в конусе» и пластины.
4. Впиши длины и количество свай.
5. Нажми **Рассчитать раскрой**.
6. Смотри число труб и схемы. Подпись «Схема 1 — 45 труб» значит: так резать 45 труб.
7. Нажми **Скачать PDF** и сохрани или распечатай.

Расчёт в вкладке не запоминается. Сначала PDF, потом можно закрыть страницу.

Если ссылка не открывается — возможно, на работе закрыт сайт github.io. Тогда нужен ИТ или другая выкладка.

## Формулы

«Конус в конусе»:

```
длина A + длина B − 2 × длина конуса + длина «конус в конусе»
```

Пропил только между отрезками на одной трубе:

```
занято = сумма длин блоков + пропил × (число блоков − 1)
```

## Запуск у себя на компьютере

Нужен Node.js.

```
npm install
npm run dev
```

Открыть адрес из терминала, обычно http://localhost:5173
