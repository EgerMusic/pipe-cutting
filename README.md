# Раскрой труб

Простая программа для раскроя конусных свай.

Считаем, сколько труб по 12 метров надо купить, и как их резать. Можно учесть «конус в конусе», пропил и минимальный остаток. Результат можно скачать в PDF.

## Как запустить

Нужен установленный Node.js.

В папке проекта:

```
npm install
npm run dev
```

Потом открыть в браузере ссылку, которую покажет терминал. Обычно это http://localhost:5173

## Как пользоваться

1. Указать длину заготовки (обычно 12000 мм)
2. Указать пропил
3. Указать минимальный остаток (сейчас по умолчанию 150 мм)
4. Если нужно — включить «конус в конусе» и вписать длины конуса
5. Добавить изделия: длина и количество
6. Нажать «Рассчитать раскрой»
7. Если надо — нажать «Скачать PDF»

## Про «конус в конусе»

Если две сваи режутся одна в другой, расход считается так:

```
длина A + длина B - 2 × длина конуса + длина «конус в конусе»
```

Плюс ещё пропил на каждый блок реза.

## Что умеет

- считает минимум труб
- раскладывает разные длины на одну трубу, если влезают
- группирует одинаковые схемы (схема × сколько штук)
- сохраняет результат в PDF
